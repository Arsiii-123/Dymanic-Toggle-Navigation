Dynamic Toggle Navigation

Built by Arslan for the Pynexia Frontend Internship. This project shows a responsive menu with a hamburger drawer, smooth hover effects and active link highlighting.

Try it: open the menu, click a link, press Esc, or tap the dark area to close it.

About

This page uses event listeners to toggle classes, CSS transitions for every movement, and DOM updates to keep the active link in sync as you scroll.

Services

Hover each link to see the underline grow. Press a link to feel the small scale effect. The active page is highlighted automatically.

Contact

The drawer closes by itself after you pick a link, and the page scrolls to the right section.
